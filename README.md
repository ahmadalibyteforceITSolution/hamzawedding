# 💍 Walima Ceremony - Hamza Nawaz & Laiba Waheed
### Royal Digital Wedding Web Application

A digital wedding invitation web application built with **Vue 3**, **Vite**, and **Tailwind CSS**. Designed to match the wedding invitation card with authentic royal typography, traditional wedding shehnai & sitar music, RSVP management, calendar event downloads, and responsive UI.

---

## ✨ Features

- 💌 **Interactive Royal 3D Envelope**: Stamped with wax monogram "H & L", opens with paper rustle and harp chime SFX.
- 🎵 **Wedding Music Player**: Plays background traditional Walima Shehnai melody with interactive visualizer, volume control, mute, and offline Web Audio synthesizer fallback.
- ⏱️ **Live Countdown Timer**: Real-time countdown to Sunday, 6th December 2026, 7:00 PM (Lahore, Pakistan).
- 📥 **One-Click Download Center**:
  - **High-Res Invitation Card (JPG)**: Direct download of the original wedding card.
  - **Calendar File (.ics)**: Save event into iPhone, Android, Google Calendar, or Outlook.
  - **Google Calendar Direct Sync**: One-tap link to add the event with venue location and details.
  - **Wedding Music Track (WAV)**: Download the festive shehnai audio.
- 📍 **Venue & Location Details**:
  - Hotel Dua Event Marriage Hall, Poonch Road, Samanabad, Lahore, Pakistan.
  - Quick "Open in Google Maps" and "Copy Address" buttons.
- ⏳ **Program Flow / Timeline**: Full evening schedule from guest arrival (7:00 PM) to couple entrance, feast, and photo sessions.
- 👥 **Respected Hosts ("Received By")**:
  - *Column 1*: Muhammad Nawaz, Abdul Hafeez, Mumtaz Ahmad, Gulzar Subhani.
  - *Column 2*: Azhar Hafeez, Asad Ali, Moeez Nawaz, Zain Nawaz.
- 📝 **RSVP & Attendance System**:
  - Full guest response form with attendance status and guest head-count.
  - Instant celebration confetti burst.
  - **Download RSVP Guest List (CSV)** for host family records.
- 🤲 **Blessings & Du'as Guestbook**: Guests can submit heartfelt prayers and like other blessings.
- 🌸 **Subtle Rose Petals Shower**: Real-time floating canvas animation with a "Shower Blessings" burst button.
- 🚀 **Vercel Ready**: Preconfigured with `vercel.json` for one-click deployment.

## 🛠️ Tech Stack

- **Vue 3** (Composition API, `<script setup>`)
- **Vite 6** (Blazing fast bundling & dev server)
- **Tailwind CSS** (Custom gold gradients, royal burgundy palette)
- **Google Fonts** (Amiri Arabic Calligraphy, Alex Brush, Great Vibes, Playfair Display, Montserrat)
- **Canvas-Confetti** (Joyful celebration animations)
- **Web Audio API & HTML5 Audio** (Wedding Shehnai and SFX)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates production-ready optimized static files in `dist/`.

---

## 🌐 Deploy to Vercel

This repository includes a `vercel.json` file. You can deploy directly with:

```bash
npx vercel
```
Or connect this GitHub repository (`https://github.com/ahmadalibyteforceITSolution/hamzawedding.git`) to your [Vercel Dashboard](https://vercel.com) for automatic CI/CD deployment on every push to the `main` branch.
